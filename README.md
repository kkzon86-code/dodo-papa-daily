# 🧸 도도아빠의 일상 — 시안 v1

4살·7살 두 아들 아빠의 육아템·장난감·나들이 큐레이션 사이트의 **첫 번째 동작하는 시안**입니다.
빌드 도구 없이 `index.html` 하나로 열리고, 그대로 GitHub Pages·Netlify에 올릴 수 있습니다.

- 미리보기 이미지: `../downloads/site-preview.png` (데스크톱+모바일 합본)
- 파일: `index.html` (사이트 전부) · `README.md` (이 문서)
- `test_site.py`, `site_shots.py`, `make_preview.py` 는 검증·캡처용 개발 파일이라 **배포할 때는 안 올려도 됩니다.**
  (이 작업환경에서 다시 렌더링할 때는 `LD_LIBRARY_PATH=/workspace/syslibs/root/usr/lib/x86_64-linux-gnu python test_site.py` 처럼 실행합니다.)

## 1. 바로 열어 보기

`index.html` 을 더블클릭하면 브라우저에서 열립니다. 인터넷 없이도 동작하고,
모바일에서는 화면 폭에 맞춰 카드가 1열로 바뀝니다.

## 2. 내 콘텐츠로 바꾸기 (제일 중요)

`index.html` 아래쪽 `<script>` 안의 **`ITEMS` 배열**만 고치면 카드 내용이 바뀝니다.

```js
{
  id: 'duplo-10474',          // 카드 구분용 이름 (아무거나, 중복만 피하기)
  cat: 'toy',                 // 'toy'(장난감) | 'outing'(나들이) | 'gear'(육아템)
  ages: ['4', 'together'],    // '4' | '7' | 'together' — 여러 개 OK
  emoji: '🚗',                // 사진이 없을 때 보이는 이모지
  title: '레고 듀플로 10474 나의 첫 자동차',
  price: '정가 29,900원 · 할인가 24,200원 (2026.11 확인)',
  verdict: '아빠의 실전 한줄평',
  reason: '왜 추천하는지',
  caution: '주의할 점 (안 맞는 집은 안 맞다고)',
  tags: ['블록', '조립'],      // 검색에도 걸리는 키워드
  url: '#',                   // ★ 여기에 내 제휴 링크를 붙여넣기
  image: ''                   // (선택) 상품 사진 URL. 넣으면 이모지 대신 사진이 나옴
}
```

- **제휴 링크 넣기**: `url: '#'` 을 `url: 'https://link.coupang.com/a/...'` 처럼 바꾸면
  `최저가·상세 보기` 버튼이 새 창으로 열립니다. (`rel="nofollow sponsored"` 는 그대로 두세요 — 제휴 링크 표시입니다.)
- **사진 넣기**: 상품 이미지 주소를 `image` 에 넣으면 썸네일이 사진으로 바뀝니다.
  파일로 가지고 있다면 `images/duplo.jpg` 처럼 같은 폴더에 두고 경로를 적으면 됩니다.
- **카드 추가/삭제**: `ITEMS` 에 `{ ... }` 를 추가하거나 지우면 됩니다.
  카테고리 탭의 숫자(전체 6, 장난감 2 …)는 자동으로 다시 계산됩니다.
- **카테고리 이름 바꾸기**: `const CAT_LABEL = { toy: '장난감', outing: '나들이', gear: '육아템' };`
- **연령 필터 이름 바꾸기**: `const AGE_LABEL` (예: '4살 추천' → '4세 추천')

## 3. 브랜드·문구 바꾸기

| 바꿀 것 | 위치 |
| --- | --- |
| 사이트 이름·한 줄 소개 | `<header>` 안 `.brand`, `<footer>` 안 `.brand` |
| 브라우저 탭 제목·검색 설명 | `<title>`, `<meta name="description">` |
| 히어로 큰 문구 | `.hero-copy` 의 `<h1>`, `<p class="lead">` |
| 이번 주 메모 카드 | `.note-card` 안 (지워도 레이아웃은 유지됩니다) |
| 문의 이메일 | `.note` 안 `hello@example.com` |
| **공정위 문구** | `<footer>` 안 `.disclosure` — **지우지 마세요** (제휴 마케팅 필수 고지) |
| 시안 표시 띠 | 맨 위 `<div class="demo-bar">…</div>` 한 줄 삭제 |
| 헤더의 `DEMO` 칩 | `<span class="chip-demo">DEMO</span>` 삭제 |

색을 바꾸고 싶으면 CSS 맨 위 `:root` 의 `--accent`(주황), `--cream`(배경), `--ink`(글자)만 바꿔도 전체 톤이 바뀝니다.

## 4. 배포하기

**GitHub Pages**
1. GitHub에 새 저장소를 만들고 `index.html` 을 올립니다(드래그 업로드 가능).
2. 저장소 → Settings → Pages → Source: `Deploy from a branch` → `main` / `/(root)` → Save.
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 으로 열립니다.

**Netlify (제일 간단)**
1. https://app.netlify.com/drop 에 `index.html` 을 끌어다 놓으면 끝. 주소가 바로 나옵니다.
2. 나중에 도메인을 붙이려면 Site settings → Domain management.

> 쿠팡 파트너스는 **사이트 심사**를 거칩니다. 카드가 6개뿐인 한 페이지보다
> ① 소개 페이지 ② 개인정보처리방침 ③ 글(리뷰) 몇 편이 있는 사이트가 통과에 유리합니다.
